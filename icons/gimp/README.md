# GIMP icons

Symbolic icons from GIMP 3.2.4 (`icons/Default/scalable/apps/*-symbolic.svg`, https://gitlab.gnome.org/GNOME/gimp-data).

- Authors: GNOME design team (mostly Barbara Muraus, some Jakub Steiner), Adwaita icon theme authors, GIMP team
- License: CC BY-SA 3.0 US or CC BY-SA 4.0 depending on the icon, see GIMP's `icons/Default/COPYING`
- Changes: base color `#bebebe` (which GIMP recolors at runtime to its theme) replaced by `#e0e0e0`; `-symbolic` suffix dropped
